## What this is
My Week 5 lab. I used list comprehensions, lambda, and NumPy to analyse 60 days of Kigali weather (September to October 2026).

## Files
- `Week5_MugaboJason(29363).ipynb`: my notebook with all the answers
- `week5_kigali_weather.csv`: the weather data

## How to run
1. Put the notebook and the CSV file in the same folder.
2. Open the notebook in Jupyter.
3. Click Kernel, then Restart & Run All.

## Main results
- Average temperature: 24.00 °C
- Hottest day: 2026-09-17 (28.6 °C)
- Hot days (26 °C or more): 18
- Rainy days: 16, total rain 331.2 mm
- First 30 days averaged 26.21 °C and the last 30 days averaged 21.78 °C, so Kigali got cooler.
