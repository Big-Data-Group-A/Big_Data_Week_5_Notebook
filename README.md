# Week 5 Lab — Advanced Python + NumPy

This notebook was created for the AUCA Introduction to Big Data Analytics course by MUKUNZI Eduine (ID: 29275). It analyzes a 60-day Kigali weather dataset using Python and NumPy, covering list comprehensions, lambda functions, array operations, boolean masking, anomalies, and trend analysis. The project loads the weather data, converts date values, and computes summaries such as mean temperature, hottest day, rainy days, and temperature differences across time periods.

The workflow highlights how NumPy vectorization simplifies repeated calculations while still allowing students to understand the logic behind loops and conditional logic. The analysis shows that the average temperature in the first 30 days was 26.21°C, compared with 21.78°C in the last 30 days, indicating a cooler second half of the dataset. It also identifies rainy and hot-day patterns, helping to interpret key weather behavior from the recorded daily values.
