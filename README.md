## Overview

This lab practises list comprehensions, `lambda` functions, NumPy arrays, boolean masking and simple anomaly and trend detection. The dataset has 60 days of Kigali weather (1 September to 30 October 2026) with temperature, rainfall and humidity.

## How to run

1. Install the requirements: `pip install numpy pandas openpyxl jupyter`
2. Keep `week5_kigali_weather.xlsx` in the same folder as the notebook.
3. Open `Week5_YourName.ipynb` in Jupyter Notebook and choose **Run → Run All Cells**.

## What is covered

- **Part 1 · List comprehensions:** Fahrenheit conversion, filtering, and converting strings to floats.
- **Part 2 · lambda:** ranking with `sorted(..., key=lambda ...)` and finding the wettest day with `max`.
- **Part 3 · NumPy arrays:** speed test (list vs array), summary statistics, and the hottest day with `np.argmax`.
- **Part 4 · Boolean masking:** hot days, rain report, and cross-array analysis.
- **Part 5 · Anomalies and trends:** days more than 3 °C from the mean, and the first 30 days compared with the last 30.
- **Bonus:** the 5 wettest days using `zip` and `sorted`.
- **Part 6 · Reflection:** answered in the notebook.

No `for` loops are used in Parts 3–5. The only loop is in the Bonus, where it is used just for printing.

## Insight

Kigali cooled by about 4.4 °C from September to October. Rainy and dry days had almost the same average temperature, so rain did not explain the change. The season did.
