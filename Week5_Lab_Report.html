The loading pipeline parses the records into four synchronized 1D NumPy arrays: dates, temps, rain, and hum.

Part 3: NumPy Arrays & Vectorization (8 marks)

NumPy arrays store homogeneous data types in contiguous memory buffers, enabling SIMD vectorization and bypassing Python object overhead.

Exercise 3.1 — The Speed Test: Multiplied 1,000,000 integers by 2 using standard Python list comprehension versus NumPy array multiplication.

import time nums = list(range(1_000_000)) arr = np.arange(1_000_000) start = time.time(); slow = [n * 2 for n in nums]; loop_time = time.time() - start start = time.time(); fast = arr * 2; numpy_time = time.time() - start print(f"Loop: {loop_time:.4f}s NumPy: {numpy_time:.4f}s -> {loop_time / numpy_time:.0f}x faster")
Output
Loop: 0.0798s NumPy: 0.0024s -> 33x faster

Observation: NumPy achieved a ~33x speedup on the test environment due to pre-compiled C-level loops and cache locality.

5. Part 6: Reflection & Discussion

Question 1: In Week 3 you needed ~15 lines to average a column; today it was temps.mean(). What did NumPy hide from you — and why was it still important to learn the loop version first?

Abstraction Analysis: Calling temps.mean() abstracts away multiple low-level programmatic responsibilities. In procedural Python, the programmer must explicitly declare an accumulator variable, iterate sequentially through every element, maintain index bounds, guard against empty sequences, increment the sum, and finally compute the ratio between sum and length. At the hardware execution level, NumPy bypasses the Python interpreter's bytecode loop and dynamic type checking entirely. It executes optimized, pre-compiled C routines that utilize vector registers (SIMD) on contiguous memory blocks.

Pedagogical Importance: Understanding the iterative loop first is vital because it establishes algorithmic literacy. Practical big data pipelines frequently present edge cases—such as heterogeneous data streams, corrupt/missing records (NaN handling), cumulative running windows, and stateful business logic—where vectorized library calls cannot be applied directly without data restructuring. Having manual algorithmic proficiency ensures an engineer understands time and space complexity, permitting effective debugging and custom processing rather than treating high-level abstractions as mysterious black boxes.

Question 2: One insight about Kigali's weather that your analysis revealed.

Empirical Finding: The empirical data revealed a substantial seasonal cooling trend between September and October 2026. The initial 30 days (September) averaged 26.21 °C with multiple days exceeding +3 °C above the seasonal baseline, while the latter 30 days (October) cooled markedly to an average of 21.78 °C (a net drop of 4.43 °C).

Counter-intuitively, precipitation was not the primary factor cooling the city on a day-to-day basis. The average temperature on rainy days was 24.14 °C, which was slightly higher than the dry day average of 23.95 °C. In addition, all five top wettest days occurred in September, during the warmer period. This demonstrates that Kigali's temperature decrease in late October is driven by broad macro-scale climatological shifts rather than immediate surface rain-cooling.
